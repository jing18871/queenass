# 靜靜小金庫

單一檔案的記帳網頁（`index.html`），資料存在瀏覽器本機。

## 用 GitHub Desktop 上傳
1. GitHub Desktop → File → New repository，名稱例如 `jingjing-vault`，Local path 選一個資料夾。
2. 把 `index.html` 和 `README.md` 複製進那個資料夾。
3. 回到 GitHub Desktop，左下角寫 Summary，按 Commit to main，再按 Publish repository。
4. 到 GitHub 網頁該 repo → Settings → Pages → Branch 選 main / root → Save。
5. 幾分鐘後網址是 https://你的帳號.github.io/jingjing-vault/

## 注意
- 資料只在各裝置的瀏覽器裡，不會跨裝置同步；換裝置用「預算」頁底部的匯出／匯入備份。
- Pages 網址任何人都能打開，但看不到你的資料（資料不在程式裡）。
